## 📈 Improving performance

The client includes several settings that help the game run smooth on older hardware. Navigate to the "Settings" tab in the main menu to adjust these. 

### Render distance
Lowering this value reduces the number of blocks the engine draws at once. A setting between 8 and 12 chunks offers a good balance between view distance and speed.

### Frame rate limit
Setting a limit to your monitor refresh rate saves power and prevents your graphics card from working too hard. If you have a 60Hz monitor, set your limit to 60 frames per second.

### Visual effects
Turning off animations like clouds, particles, and smooth shadows helps the game maintain a high frame rate in busy areas.

## 🧩 Troubleshooting common issues

Most problems have simple solutions. Read these tips before you reach out for help.

### The game does not launch
Verify your Java installation. The client requires the correct version to interact with Minecraft. Visit the official Java website to download the latest runtime environment if the client reports an error about missing Java.

### The screen looks blurry
Check your resolution settings within the game. Ensure the game resolution matches the native resolution of your monitor. You can change this in the "Video Settings" menu inside the game world.

### The connection to the servers fails
Check your local internet connection. Sometimes security software or firewalls block the client. Ensure that the game has permission to access the internet through your Windows Firewall settings.
